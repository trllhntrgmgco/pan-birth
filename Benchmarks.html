Benchmark Methodology
All metrics computed from live system data — no self-reporting, no external evaluation. Pulled from SQLite (8 mind.db + 1 omni-truth.db) via API endpoints. Refreshes every 15 seconds.
Data Sources
/api/omni/stats · /api/city/state · /api/city/strengths · /api/city/ethics · /api/omni/strength-stats/{alpha}
B1–B3: omni-truth.db aggregates. B4: per-Alpha ethics_log. B5: per-Alpha strength_metrics. B6: omni-truth.db alphaContributions + strength_knowledge_log. B7: per-Alpha mind.db tables. B8: omni-truth.db domain distribution. B9: strength_knowledge_log GROUP BY.
